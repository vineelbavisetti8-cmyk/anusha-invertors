# anusha-invertors

Official web application for **Anusha Batteries & Inverters** — Power Backup Solutions in Eluru, Andhra Pradesh.

## Features
- **3D Hero Scene**: Three.js & React Three Fiber interactive scene with WebGL capability detection and smooth fallback.
- **Modern Next.js Architecture**: Next.js App Router with TypeScript and Tailwind CSS.
- **Product Catalog**: Tubular batteries, inverters, combos, and UPS backup systems with verified specifications.
- **Interactive Power Flow**: Visual explanation of grid-to-battery-to-load inverter power systems.
- **Store Location & Directions**: Direct integration with Google Maps and local store details in Powerpet, Eluru.
- **SEO & Structured Data**: Pre-configured JSON-LD schema (LocalBusiness), sitemap, and robots.txt.

## Getting Started

First, install dependencies:

```bash
npm install --legacy-peer-deps
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
